# 🐶 Dog_pic_generator

A React-based web application that allows users to generate AI-powered images of dogs in various styles.

## 🚀 Features

- **AI-Powered Image Generation**: Generate realistic or artistic dog images using advanced AI algorithms.
- **Customizable Styles**: Choose from a variety of styles, including realistic, cartoon, and abstract.
- **User-Friendly Interface**: Simple and intuitive design for easy navigation.
- **Fast Performance**: Built with React and Vite for a smooth user experience.


### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)
